## 🌐 Overview & Capabilities

This platform demonstrates high-budget digital engineering capabilities:
- **WebGL Spatial Canvas**: Real-time rendering of interactive 3D viewports with hardware-accelerated shaders.
- **Micro-Interaction Physics**: Kinetic cursor interactions, inertial damping, and spring physics powered by Motion.
- **Server-Side Gemini AI**: Dynamic content generation and conversational capabilities backed by `@google/genai`.
- **Zero-Latency Bun Pipeline**: Package management, building, and bundling executed via Bun.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (TypeScript, App Router, React Server Components)
- **3D Graphics Engine**: Three.js (`@types/three`), WebGL Canvas
- **Motion & Styling**: TailwindCSS, Class Variance Authority (`cva`), `clsx`, Framer Motion
- **Runtime**: Bun (`bun.lock`) / Node.js 20+

## 🚀 Running Locally

```bash
git clone https://github.com/vickyiitp/devil-labs-demo-platform.git
cd devil-labs-demo-platform

# Install with Bun or npm
bun install
# or: npm install

# Start development server
bun dev
# or: npm run dev
```

Open **`http://localhost:3000`** in your browser.
